CloudFlare Integration

What this is NOT: This does NOT add CloudFlare to your server. This does NOT enable CDN functionality.
What this IS: If your websites already use CloudFlare as a reverse proxy/CDN, enabling this tells CSF to also add blocked IPs to your CloudFlare firewall. This means attackers get blocked at CloudFlare's edge (before they even reach your server), which is more effective.

Don't use CloudFlare? Leave everything OFF. These settings do nothing without an existing CloudFlare setup.

When CSF blocks an IP, also block it in your CloudFlare account's firewall.

"Challenge" is softer — lets real users through if they pass the CAPTCHA.

Security & Monitoring

How it works: These features actively monitor your server for suspicious activity beyond just network attacks. They watch for runaway processes, port scanning, unauthorized file changes, and coordinated attacks.
Process Tracking

Port Scan Detection

Service Integration

What this does: When you run Docker, WireGuard, Netbird, Coolify or Dokploy, this panel auto-detects those services and checks two things: (1) whether the required firewall ports are open in TCP_IN / UDP_IN, and (2) whether their internal subnets are whitelisted so LFD stops raising false alarms.
